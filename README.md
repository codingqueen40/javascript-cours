# JavaScript 2026 · le code des cours 🔥

Le code de la série YouTube **« JavaScript 2026, de zéro à ton premier projet »** de [Codingqueen40](https://www.youtube.com/@codingqueen40).

Épisode après épisode, on y construit **Code Streak** : une mini-app qui compte tes jours de code d'affilée et t'encourage.

> 💡 **Mon conseil :** regarde la vidéo et **tape le code toi-même**. C'est comme ça que tes doigts apprennent. Ce dépôt est là pour vérifier ton code, ou pour te débloquer.

## Ce que contient ce dossier

Code Streak tel qu'il est **à la fin de l'épisode 2** : 3 fichiers, 3 métiers.

```
javascript-cours/
├── index.html   → la structure : ce qu'on voit (titre, boutons, message)
├── style.css    → l'apparence : couleurs, tailles, mise en page
└── script.js    → le comportement : ce qui se passe quand on clique
```

- [`index.html`](index.html)
- [`style.css`](style.css)
- [`script.js`](script.js)

Pour copier un fichier : ouvre-le, puis clique sur l'icône **Copier** (*Copy raw file*) en haut à droite du code.

## Faire tourner Code Streak chez toi

1. Récupère les fichiers : bouton vert **Code** › **Download ZIP** en haut de cette page, puis décompresse le dossier.
   *(Tu connais Git ? `git clone https://github.com/codingqueen40/javascript-cours.git`)*
2. Ouvre le dossier dans **VS Code** (Fichier › Ouvrir le dossier…). Si un bandeau « mode Restreint » apparaît, fais confiance au dossier.
3. Ouvre `index.html`, puis lance l'aperçu avec l'extension **Live Preview** : clic droit sur `index.html` › **Show Preview**.
