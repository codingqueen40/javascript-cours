# Épisode 1 · Ta 1ʳᵉ mini-app JavaScript, sans rien installer

🇫🇷 [Français](#fr) · 🇬🇧 [English](#en)

<a id="fr"></a>

Dans cet épisode, **tout se passe dans la console du navigateur** : il n'y a pas encore de fichier de projet.

Le fichier [`console.js`](console.js) regroupe tout ce qu'on tape dans la vidéo, dans l'ordre :

1. le hook (retourner un site en 2 lignes) ;
2. tes premières lignes dans la console ;
3. prendre le contrôle d'une page (le DOM) ;
4. **Code Streak**, ta 1ʳᵉ mini-app (à taper sur une page `about:blank`) ;
5. casser ton code exprès pour apprendre à lire une erreur.

> ⚠️ Ce n'est pas un fichier à lancer : c'est un aide-mémoire. Tape les lignes une par une dans la console
> (Mac : **Cmd + Option + J** dans Chrome · Windows : **F12** › Console).

## 🎯 Le défi de la semaine

Ajoute un 2ᵉ bouton « J'ai raté un jour 😅 » qui remet le compteur à zéro. Indice : `jours = 0`.
La solution est au début de l'[épisode 2](../episode-02/).

## 🇬🇧 English · Episode 1 — Your 1st JavaScript mini-app, nothing to install

In this episode, **everything happens in the browser console**: there are no project files yet.

[`console.js`](console.js) gathers everything typed in the video, in order:

1. the hook (flip a website in 2 lines);
2. your first lines in the console;
3. taking control of a page (the DOM);
4. **Code Streak**, your 1st mini-app (to type on an `about:blank` page);
5. breaking your code on purpose to learn how to read an error.

> ⚠️ It's not a file to run: it's a cheat sheet. Type the lines one by one in the console
> (Mac: **Cmd + Option + J** in Chrome · Windows: **F12** › Console).
